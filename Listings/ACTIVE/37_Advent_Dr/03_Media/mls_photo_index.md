## How to Use These

1. Open the gallery link from `photo_links.md`
2. Find the shot that matches each slot above
3. Save it with the filename shown (e.g. `01_aerial_wide.jpg`)
4. Drop it into `03_Media/Photos/`
5. Use that filename in the campaign — the slots in `05_Ads/7day_campaign.md` already match

You do not need all 8 slots. Minimum to run the campaign: **3 photos** (one wide shot, road access, any third).
