## When photos are available

Name them using the convention in `../photo_upload_guide.md`:

| Filename | Shot |
|---|---|
| `01_aerial_wide.jpg` | Wide overview / aerial |
| `02_road_entrance.jpg` | Road / entrance |
| `03_outbuilding.jpg` | Outbuilding exterior |
| `04_treeline.jpg` | Tree line / woods |
| `05_wma_boundary.jpg` | WMA boundary |
| `06_open_acreage.jpg` | Open usable land |
| `07_structure_detail.jpg` | Any structure detail |
| `08_scenic.jpg` | Scenic / hero shot |

Minimum to launch: 3 photos (one wide shot, road access, any third).

## Sharing photos

Upload to Google Drive or Dropbox, set sharing to "Anyone with link can view,"
and paste the link into `../photo_links.md` (create that file if it doesn't exist).
