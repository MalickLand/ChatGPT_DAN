# 37 Advent Dr — Photo Upload Guide

## How to Add Photos

1. Name each photo using the format below
2. Drop them into the `03_Media/photos/` folder
3. Update the checklist at the bottom

That's it. The 7-day campaign in `05_Ads/7day_campaign.md` already has slots ready for each photo — just match the filename to the slot.

---

## Naming Convention

| Shot Type | Filename |
|---|---|
| Wide aerial / drone overview | `01_aerial_wide.jpg` |
| Road frontage / entrance | `02_road_entrance.jpg` |
| Outbuilding exterior | `03_outbuilding.jpg` |
| Tree line / wooded area | `04_treeline.jpg` |
| WMA boundary or signage | `05_wma_boundary.jpg` |
| Open usable acreage | `06_open_acreage.jpg` |
| Cabin or structure detail | `07_structure_detail.jpg` |
| Scenic / sunset / wide sky | `08_scenic.jpg` |

Use `.jpg`, `.jpeg`, or `.png` — any format works.

Phone photos are fine. You don't need drone shots to start — use what you have.

---

## Minimum for Launch

You need **at least 3 photos** to run the campaign:
- `01_aerial_wide.jpg` or `06_open_acreage.jpg` (a wide land shot)
- `02_road_entrance.jpg` (access shot)
- One of: `03_outbuilding.jpg`, `04_treeline.jpg`, or `08_scenic.jpg`

Facebook Marketplace requires at least 1. Instagram performs best with 4–5. LandWatch recommends 6+.

---

## How to Share Photos From Your Phone

**Option A — Google Drive (recommended)**
1. Upload photos to Google Drive
2. Right-click folder → Share → "Anyone with the link can view"
3. Paste the link into `03_Media/photo_links.md`

**Option B — iCloud / Dropbox / OneDrive**
Same steps — share a folder link and paste it in `photo_links.md`

**Option C — Email to yourself**
Forward to the email you check during this session, then download and rename per the guide above.
